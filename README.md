# NMAG Website — Demo

Clickable prototype of the National Museum & Art Gallery (NMAG) of Papua New Guinea website, based on the GPHA website blueprint (Next.js + Amplify CMS structure).

## Open it
Open `index.html` in any browser. Everything is in that one file; no build step.

## What's in the demo
- Public site: Home, About, Exhibitions, Collections, Plan a Visit, Learning, News, Contact, search, EN / Tok Pisin toggle, help chat
- Admin Panel (Admin link in the menu): Homepage, Content, Pages & Visit Info, Identity & Colors, Header & Menu, Footer, Widgets, Site Mode, Backup
- Admins can change pictures and text for hero slides, Director's welcome, exhibitions, collections, learning cards, news and the help chat's quick questions

## Notes
- Theme: Night & Ochre, light mode only
- All content is sample content and needs confirming with NMAG
- Edits made in the demo's Admin Panel are saved in the browser only. In the production build they will be saved to the CMS.
